# Guardian Botanical Care (GBC) 代码结构梳理文档

## 项目概述
Guardian Botanical Care 是一个植物识别与养护管理应用，支持多平台（Android、Windows），采用Flutter框架开发。

## 核心架构

### 1. 应用入口 (main.dart)
- **主要功能**：应用初始化、多平台适配、主题管理
- **特色功能**：
  - Windows平台窗口尺寸限制（模拟手机体验）
  - 多Provider状态管理（PlantProvider、SettingsProvider）
  - 启动页面（SplashScreen）
  - 底部导航栏（支持动态主题的玻璃效果）

### 2. 数据模型 (models/)
- **plant.dart**：植物信息模型
  ```
  - 植物ID、名称、学名
  - 识别日期、健康状态、置信度
  - 养护指导（浇水频率、光照需求、施肥计划）
  - JSON序列化支持
  ```

### 3. 状态管理 (providers/)
- **plant_provider.dart**：植物数据管理
- **settings_provider.dart**：应用设置管理（主题、配置等）

### 4. 核心功能界面 (screens/)

#### 4.1 主要功能模块
- **my_plants_screen.dart**：我的植物管理
- **photo_identify_screen.dart**：拍照识别核心功能
- **diagnosis_screen.dart**：专业诊断入口页面
- **care_reminder_screen.dart**：养护提醒
- **settings_screen.dart**：应用设置

#### 4.2 诊断相关功能
- **ai_diagnosis_screen.dart**：AI智能诊断
- **expert_consultation_screen.dart**：专家咨询
- **community_forum_screen.dart**：社区问答
- **ai_expert_chat_screen.dart**：AI专家对话

#### 4.3 辅助功能
- **identification_result_screen.dart**：识别结果展示
- **plant_detail_screen.dart**：植物详情页面
- **membership_screen.dart**：会员功能
- **splash_screen.dart**：启动画面

### 5. 服务层 (services/)
- **api_service.dart**：API接口服务
- **ai_chat_service.dart**：AI对话服务
- **plant_database_service.dart**：植物数据库服务
- **settings_service.dart**：设置持久化服务
- **location_service.dart**：位置服务

### 6. 主题系统 (themes/)
- **app_themes.dart**：多主题支持
  - 支持动态主题（玻璃效果）
  - 传统Material Design主题

### 7. UI组件 (widgets/)
- **apple_style_widgets.dart**：苹果风格UI组件
- **apple_animations.dart**：动画效果组件

## 主要功能流程

### 植物识别流程
1. **拍照识别** → 2. **API处理** → 3. **结果展示** → 4. **保存到我的植物**

### 诊断服务流程
1. **专业诊断入口** → 2. **选择服务类型**（AI诊断/专家咨询/社区问答）→ 3. **获取诊断结果**
